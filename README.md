# 元素变换（Chrome 扩展）

选中任意页面元素，进行旋转、翻转、缩放。对视频网站的 `<video>` 同样有效，全屏后变换仍然保持。

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 `element-transform`

## 使用

1. 点击工具栏图标（或快捷键 `Alt+Shift+R`）进入选中模式
2. 点击页面上的任意元素（优先选中点击位置下的视频）
3. 在浮出面板中：
   - **旋转**：用 ±15° / ±90° 按钮，或直接输入角度
   - **翻转**：水平 / 垂直按钮；也可设置翻转轴角度后点「按轴翻转」（0° = 上下镜像，90° = 左右镜像）
   - **缩放**：用 ± 按钮或输入倍率（如 `1.5`）
4. 需要换目标时点「重选」；点「父级」可选中外层容器
5. `Esc` 取消选中模式

拖动面板标题栏可移动面板。
